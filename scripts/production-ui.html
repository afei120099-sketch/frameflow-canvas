剧集

    新建剧集

    格式 production-episode-v1。素材字段写文件名，建好后在「素材」里拖入同名文件，画布里有的会自动补上。storyboard（分镜图）可选：写了就按分镜定构图和机位（png/jpg/webp，比例和剧集一致，草图/白模截图都行）；不写或写 null 就按 keyframePrompt 直接出图，这时 keyframePrompt 要写清景别、机位和人物位置。keyframePrompt / look 用英文、只写想要的（Flux 读不懂中文，也会把 no/不要 后面的东西画出来）；videoPrompt 就是平时队列里的 H3 提示词，<Picture 1> 是通过的关键帧。让别的 AI 来写：点「复制给 AI 的说明」，连同剧情一起发给它，把它回的 JSON 粘到这里。

    从画布导入角色

    读取打开生产线的那个画布页里的角色：脸部参考（没有就用主外观）、主外观图、主声音。只读，不改画布。保存剧集时自动上传。

    素材

    把图片拖到这里按文件名对上剧集里写的名字；也可以点下面每一项单独选文件
    按角色名、文件名、编码从画布角色和素材里找；能对上的打开剧集时已自动补上
