# H3 视频制作（总导演）

本文件是总导演：管流程、管每镜该找哪个岗位和哪条知识、管每道闸口怎么验收。细则在 h3q 里按需取，不要整库读。

## 一、工具

h3q 和本文件在同一个目录（画布用环境变量 `FRAMEFLOW_H3_TOOLS` 找它，默认 `./h3-tools`）。在这个目录里跑 `python h3q.py <命令>`。h3q 读的规则数据在同目录 `h3q_data.json`。

| 命令 | 用途 |
|---|---|
| `list` | 看模块和小节 |
| `get <模块> [小节]` | 取规则。模块：导演 / 提示词 / 动作 / 表演 / 光影 / 队列 / 审片 / Seedance |
| `find <标签或词>` | 跨模块搜：打斗 法术 对白 口型 湿态 服装 道具 手 场景 光 群戏 续接 锚点 编号 表演 声音 运行 |
| `skeleton <T2VA/I2VA/FL2VA/L2VA/Ref2VA>` | 官方格式骨架 |
| `template <ref/chain/first>` | 队列单镜模板 |
| `check <队列.json> [--all]` | 静态校验，ERROR 必须清零，WARN 改掉或逐条说明 |

按任务取：写镜头方案 → `get 导演`；写/改队列 → `get 队列` + `get 提示词 官方格式` + `get 提示词 编号` + `get 导演 逐镜对照表`，每一镜再按内容 `find`（台词 `find 口型`、道具 `find 道具`、打斗 `find 打斗`、接尾帧 `find 续接`），写完必跑 `check`；审片 → `get 审片`。工具用不了时按本文件手工执行，并告诉用户没跑 check。

## 三、流程

0. **剧本分镜**（`get 导演 剧本分镜写法`）：每场先写空间布局（门窗家具和人在画面哪边），一个 △ 只写一个机位，站位用画左/画右/前景/背景（每人同时写一个依托物：背靠窗、坐在书桌后；同场换机位只改左右、不改依托物 🧪），视线写看向谁，拍不出来的改成可见动作、特写、台词或标后期。用户给的剧本有问题，列出来问，不自己改。
1. **项目设定档** `<项目名>_设定.md`（`get 导演 项目设定档`）：风格句、角色锁、每个场景的光线句（含时间 + 主色温）、环境底声都写在这里，之后逐字复制，不现编。
2. **导演方案**：每镜写功能、秒数、**制作方式**（见下）、模式与图单、起始→动作→结束、机位和运镜理由、构图、站位视线、光、表演、声音、风险；附本集配色表、黑白检查、**转场表**（只列设计过的接缝，其余默认硬切，见 video-transition-design）。画面设计按 `get 导演 画面设计`。有参考片先逐帧拉片。
3. **制作方式分配**（每镜先定用什么做，不默认全用提示词硬拍）：
   | 方式 | 什么时候用 |
   |---|---|
   | 纯 H3 | 默认 |
   | H3 + 白模 | 站位、朝向、视线、水流方向、多人占位说不清；同类问题返修过一次的 |
   | 首尾帧链 | 同场同人同机位、动作连续（见第五节「接尾帧」） |
   | 代码 | 片头片名、字卡、粒子叠加、墨晕等风格化转场、定格褪色 |
   | H3 + 代码合成 | 真实画面 + 风格化过渡（例：画里、画外各渲一段，代码做墨晕遮罩） |
   | 后期 | 变速、闪白黑场、调色、补音效、拖影 |
   模型能力达不到的（例：慢镜头美感、精确按帧动作）不靠反复改提示词，改用后期或代码。
4. **逐镜对照表（硬性）** `<队列名>_对照表.md`：方案批准后、写提示词前先写。每镜：剧本原文 → 一个机位 → 开始（站位 + 服装状态）→ 时间段（一段一个看得见的动作，剧本的动作全落进去、不加剧本没有的）→ 结束（标志姿态怎么结束也写）→ 拍不出或矛盾（有就停下问）→ 取过的规则。提示词只照对照表写。
5. **写队列**：新项目或改了写法的，先写并投第 1 镜小样；每个新场景第 1 镜投小样，通过后本场其余镜头一次写完一次交。用户批准才写正式队列；「好/继续」只批准下一步，不等于投 GPU。
6. **交付**：附 check 结果、未覆盖项、每镜风险、「合计 X 秒 / 目标 Y 秒」；提醒先 validateOnly 干跑、先投小样（测试和小样 megapixels 0.45）。
7. **审片返修**：见第八节。

不变的约定：不改已批准的剧情、台词、人设；旧队列不覆盖，新版另存；用户单独改某一镜时只回这一镜；用户让改什么才改什么。难拍的画面按 `get 导演 可拍性` 分情况处理，重要的照拍并定降险手段，不为难拍删重要画面。三道独立审核（故事定稿后、提交前、成片后）各另开一个没看过制作过程的助手（`get 导演 交付顺序`）。

## 四、提示词写法（官方 Ref2VA 六段式）

✅ 依据（实测）：同一镜同人同图同种子，官方六段式 19/19 条干净，旧中文写法每条多 0.8～1.4 段人声。队列模板：`h3q template ref`。

**六栏**依次写，栏目名英文原样、行首、后跟冒号：`subject_definitions:` / `summary:` / `retention_analysis:` / `detailed_description:` / `overall_soundscape:` / `non_diegetic_music:`。除 `<d>` 里的台词和画面上看得见的字，全部英文。

- **Subject**：人物、场景都定义成 `<Subject N>`，一行一个，写明来自哪张图（`<Subject 4> is Wang Wu from <Picture 4>, a man in his fifties …`）。人名只出现在 subject_definitions，后面一律用 `<Subject N>`。
- **summary**：开头 `[reference generation]`（接尾帧/定稿首帧写 `[keyframe completion + reference generation]`），只写谁做了什么、说了几句什么样的话，不写台词原文。
- **retention_analysis**：每个 Subject 一行 `fully_preserved - …`。接尾帧加一行 opening frame fully_preserved。
- **detailed_description**：先一两句整体风格（五项见下），再 `[Shot 1] …`；后面写 `[Shot 2] At 00:04.000, the shot cuts to …`，只写切点时刻，不写时间段。固定机位一个镜头就只有 `[Shot 1]`，动作按先后写。结尾写 `The final frame holds on …`，最后 1～2 秒写还在进行的动作。接尾帧的镜头正文以 `The shot begins exactly on the opening frame…` 开头。
- **台词**：`<Subject 4>, a man in his fifties with a low, slightly rough voice (S1), asks under his breath: <d>[Chinese] 报告改完了吗？</d> He closes his mouth …`。S1、S2 按第一次出声先后给，不说话的人不给；`<d>` 里只放 `[Chinese]` + 空格 + 原话 + 句末标点；台词意思不在外面用英文再说一遍；每句后写闭嘴。**队列 `dialogue` 留空 []**（非空时画布会追加名字和录音，导致念名字、乱说话）。
- **台词内容**：口语（啊、呢、吧，可以停顿重复）、短句、一次一个信息；不以喊对方名字开头；赌约、交易类台词先把规则说对再加戏（h3q 报 `[台词语感]`，只报不改）；说话时长 ≥ 字数 ÷ 3.5 秒（⚠️ 实测台词没有截断、语速偏慢，不再多留 0.5 秒；用户剪辑时整体加速 1.1～1.2 倍，渲染时说话偏慢没关系）；已批准的台词不自己改，发现问题列出来问。
- **声音**：`overall_soundscape` 写环境声和这一镜的动作声；不要配乐写 `non_diegetic_music: N/A`。关键动作声写材质和音色、写成明显的声音（很轻的声音出不来，要就后期加）。环境声默认安静，少堆声源。
- **全部正面描述**：不写禁止句（no music、不出声、没有背景音乐、no logos 等）。要某样东西不出现，就正面写它是什么样（例：雾写成「tall, vertical and motionless like a solid pale wall…」）。h3q 扫正文里的 no / not / never / without，报 WARN `[否定词]`。
- **比喻、虚假精度、残留话不进正文**🧪：模型会把比喻里的名词画成真物件（「端坐如钟」会挂出一口大钟）。人物姿态、动作、光、影、情绪不用 like a… / as if 这类比喻；**材质、形态类比喻可以保留**（上面雾 like a solid pale wall 就是刻意让雾有形），但要确认它就是想画成的样子。不写百分比、`mm of pupil` 这类说明书数字，不写占位语（TBD、同上一镜）、AI 开场白、J-cut / ST001 这类工程剪辑术语。h3q 报 HINT `[修辞]` `[虚假精度]`、WARN `[文本残留]`。
- **logo**：永远不写 no logos / no signs / no lettering；改写 `Any logos, signs and brand marks that appear in the reference pictures stay exactly as they are`，只对凭空编造的字写 `carry no invented writing`。
- **原样提交**：不要画布追加句（「这段听到的」、`Audible audio is…`）；官方格式队列 `defaults.noBackgroundMusic` 写 false。不用 `{{本集.…}}` 占位，风格句、光线句每镜写完整英文。

**按镜头类型选格式**（h3q 自动判断，对不上报 `[官方·类型]` ERROR）：
| 镜头 | 判断 | 写法 | 状态 |
|---|---|---|---|
| 参考图出片（最常用） | 绑了场景图或角色图 | 六段式 | ✅ |
| 接尾帧 / 定稿首帧 + 参考图 | 有首帧，同时绑了参考图 | 六段式，summary 写 `[keyframe completion + reference generation]` | 🧪 照官方指南，待出片确认 |
| T2VA / I2VA / FL2VA / L2VA | 没有参考图 | 三栏式 `integrated_multimodal_description:` / `overall_soundscape:` / `non_diegetic_music:`，首尾帧对齐句照 `skeleton` | 🧪 照官方指南，未实测；首次先干跑看编号 |
| 视频延长 extend | — | 停用，接续一律用接尾帧 | — |

**送角色声音**（可选）🧪：Ref2VA 镜头写 `"voiceRoleIds": [S1 的角色ID, S2 …]`（最多 3 个，都在 roleIds 里），正文在四处写 `<Audio N>`：subject_definitions 末尾 `<Audio 1> is the voice-timbre reference for <Subject 4> (S1).`；summary 写 `[reference generation + audio reference]` 并加一句说明；retention_analysis 末尾 `<Audio 1>: reference - its vocal timbre guides the dialogue delivery of <Subject 4> without copying the original signal.`；每句台词前 `…(S1), using the voice timbre referenced from <Audio 1>, says: <d>…`。不送就两样都不写。测试 5/5 不乱说话、音高往样本靠；音色统一没经人耳确认；只有一个字的回应（「嗯」）送声音后 1/3 没说出来。画布提交只送样本前 8 秒，样本开头要是干净人声。

## 五、每镜硬规则

**五项必写**（缺或写错 h3q 报 `[五项·类别]` ERROR，画布拦截）：
| 项 | 写了 | 写对 |
|---|---|---|
| 风格胶片 | 一句含胶片或颗粒（Kodak Vision3 250D / film grain） | 整集一种胶片型号 |
| 光线 | 光源 + 方向 + 色温 + 亮在哪 | 同一场景逐字照抄；不写「只有一盏灯」类句子 |
| 景别焦段 | 一个景别词 + 焦段或景深 | 一个机位只有一个主景别，要变写清从哪推到哪 |
| 构图 | 主体在画面哪里 + 前景/后景/景深至少一样 | — |
| 运镜机位 | 高度或角度 + 怎么动（fixed / push in / track / pan） | 同一句里不能既 fixed 又推跟 |

官方格式的景别、机位角度、运镜写进每个 [Shot]，第 2 个起缺项 h3q 报 WARN `[分镜五项]`。**景别只写它装得下的东西**（H3 会把看不见的内容强行画进来：脸被裁、人被缩小；h3q 报 `[景别内容]`）🧪：
| 景别 | 装得下 | 不写 |
|---|---|---|
| 特写 / 大特写 | 脸、眼、手、一件小物 | 胸部以下的身体、走动、大幅动作、夸张表情 |
| 中近景 | 胸部以上 | 全身 |
| 手 / 道具局部镜（嘴不在画内） | 手和物 | 画内台词（模型会硬塞一张脸） |

**编号**：`<Picture k>` 只按参考图顺序从 1 数，场景图在前、角色图在后；首帧/尾帧**不占编号**，正文写 the opening frame / the final frame。画布提交时会自己把首帧放到 Picture 1、其余 +1，**不要手动 +1**（会挪两次，换脸）。✅（实测）总图数 ≤ 9；每张图职责单一，人物图写 use ONLY for face/body/clothes；两张图管同一件事要写明听谁的。

**字段**：title 全队列唯一（接帧靠标题）；roleIds、sceneAssetIds 必填可空；seconds 5～15；soundMode 只能 av / ambient / silent，有台词必须 av；**ID 字段只填真实 ID**（8-4-4-4-12 位），角色没建就先在画布角色库建。

**模式**：有定稿首帧 → first-last + firstFrameAssetId；场首/换场 → auto 全能参考；同场连续承接 → firstFrameFrom 上一镜 last；钉落点 → 加 lastFrameAssetId；中间钉状态 → timeAnchors 🧪。

**接尾帧**：四条**都**满足才接：同一场景图且时间连着、同一组人、同一机位（景别角度焦段不变）、上一镜结束 = 这一镜开始。切镜、正反打、过肩、主观、插入、空镜、换人换地点跳时间都不接。代价：上一镜的瑕疵会带过来，要等上一镜出片挑定再跑这一镜。🧪 连接 3 次（4 镜）后回一次全能参考。写法：`"generationMode": "first-last"` + `"firstFrameFrom": {"shot": "<上一镜完整标题>", "frame": "last"}`，场景图、角色图照常绑。h3q 条件全对上会报 HINT `[接尾帧]` 提示；已接的镜还核对景别咬合（上一镜结尾景别 ≠ 这一镜 [Shot 1] 景别报 WARN `[接尾帧·景别]`）。

**时长**：长镜头靠内容撑，每 1～3 秒要有新信息（动作、反应、表情、台词、机位变化）。有戏的镜头 10～15 秒；插入镜、空镜、屏幕特写 5～6 秒。开头 1 秒内进事件；结尾不拖。估算：说话 ≥ 字数÷3.5 秒，一个动作 1.5～2.5 秒，小反应 0.5～1 秒，没有新变化的段 ≤ 2 秒。确实需要留白的保留原秒数，在对照表写一句为什么。（官方格式没有时间段，h3q 按整镜台词核算：字数÷3.5 + 标点停顿 + 末尾 1 秒，超过 seconds 报 `[时长] 偏短`；低声说分母 3.0，喊或抢话 5.0；动作和反应的估算人工核对。）

**细节自查**（`get 提示词 细节清单`）：景别焦段景深；主体位置；每人站位、距离、朝向、**视线看着谁**（说话的人看着对方，写死「eyes fixed on <Subject N>」；🧪 单人特写点名对方，对方不在画内时可能被画进画框或克隆，待小样对照，现有写法不改，见 `find 表演`；一个 [Shot] 只写一个视线落点，要换视线开新的 [Shot]，h3q 报 `[视线]`）；每个出镜角色每段都有看得见的反应（不说话的人也要有）；道具写左手/右手；每个动作的声音。
- **服装状态**：对照表「开始」「结束」写每个出镜人的服装状态，上一镜结束 = 下一镜开始；只有标明换衣的镜头可以变。
- **身份核对**：roleId、Subject 编号指向的图、台词的说话人、当前那套服装、站位视线，逐人对上。
- **参考图状态偏离**🧪：角色参考图里戴着/穿着的东西，本镜要摘下、脱下时，模型会叠加而不是替换（头盔头上一个、怀里又一个）。subject_definitions 行和这一镜都写「In this shot <Subject N> is not wearing the helmet shown in <Picture N>; this description overrides the reference picture」，再写取下后本体的样子；持续 ≥2 镜的变化换参考图或接尾帧，不靠文字（h3q 报 WARN `[参考图状态]`）。
- **标志姿态要显式交接**🧪：趴着、坐起、靠墙、拎着东西这类标志姿态，写清谁建立、何时结束、结束后变成什么（正面写：sits upright with both hands back on the table），旁边的配角写保持原姿；不写，模型会把姿态挂到最近的另一个人身上。对照表「结束」栏写。
- **易错画面**：进出门写清机位在门哪侧、谁在门内外；远景人群写「慢步走」（不写热闹、人潮涌动）；作用在某人身上的道具写明作用对象和位置；水流、风向、运动方向用画面方位写（从画面上方流向下方），不用东南西北；害羞、心动不写脸红、耳朵红、blush（⚠️ H3 会把脸和耳朵整片渲红），改用动作写（垂眼又抬眼、咬唇、把脸埋进对方肩上），见 `find 表演`；过肩镜头越过 A 右肩 → A 在画面左前景（写 foreground，前景虚焦的人只写肩背不写动作，h3q 报 `[构图层次]`）；背景群体点名到人头（one of them raises a hand while the other two sit still），教室、街、食堂这类公共场景不写「无其他人物」（h3q 报 HINT `[背景人物]`）；🧪 反光小物件（玉佩、首饰、镜面）只写材质本色、不和光同句，待小样验证（见 `get 光影 材质`，h3q 报 HINT `[反光道具]`）。

**同场一致**：同一场景时间和主色温不变，光线句逐字复制；剧情换时间就当新场景。画面亮暗主要听场景图，正文写「再亮一档」压不过它，要亮就换图或后期调色。

**打斗法术**：发力线 + 接触硬停 + 代价 + 物理反馈（衣发、尘石、雾）；法光只在接触瞬间 ≤ 0.5 秒薄闪，写颜色亮度上限。一镜一个主动作，独立机制多就拆镜。

**慢镜头**：写真实高速摄影（Phantom 1000fps、正常速度回放、动作连续不停顿），写清每一阶段的形态变化。✅ 结论：写泛了就像普通片段放慢；写细了也受模型能力限制，美感不够的改用后期变速或代码补帧。

## 六、白模导演台（只定空间）

画布自带，正字「白模」，不是即梦白模。入口：顶栏【导演台】→ 选场景 →【打开白模导演台（3D）】；或场景详情 →「白模首帧（Blender）」/「写实首帧（Depth → SDXL）」。
- 用：站位乱、跳轴、机位飘、多人位置说不清、视线方向反复错。空镜、已有稳定场景母版加接尾帧链、纯对白特写不必过白模。
- 能做：摆房间尺寸、方盒/平面、机位；Blender 出首帧（16:9 = 1280×720）；Depth → SDXL 出写实首帧；发送到 H3 当首帧/首尾帧/参考图。坐标 Y 朝上、原点地面中心、机位朝本地 −Z、单位米。
- 不能做：深度图、遮罩、物体 ID 不能当 H3 的 ControlNet 输入；灰模图不当视觉参考（会复制灰塑料质感）。把站位换算成画左画右、相距多少写进正文。
- 🧪 还没实测。详细文档见画布仓库 `docs/director-stage/`。

## 八、审片、复盘与规则怎么长

**验收闸口**：PASS-PAPER（check）→ PASS-IMPORT（干跑看 compiledShots）→ PASS-RENDER（看片）→ PASS-CUT（拼接成片）。

**审片**：只给 通过 / 局部修改 / 重做 + 依据。用户在看片时先收集问题，等用户说完再一起改。返修一次只改一个变量；同类错误 2～3 次没改善就换方法（白模、代码、后期），不盲目重渲。返修队列单独出、标题加版本后缀，接尾帧的链在同一队列里重接。出问题先剪、先用代码修，再考虑重渲，旧片段保留；后期全用代码做（`get 审片 后期`）。

**失败归因**：每个返修镜头归到一类——提示词写法 / 参考图 / 模型能力 / 种子运气 / 剧本本身。只有「提示词写法」类才可能变成规则；「模型能力」类改换制作方式。

**规则怎么长**（防止正本越写越胖）：
1. 新发现的问题先写进知识库（h3q_data.json）对应小节，格式「现象 / 根因 / 写法 / 日期」，标 🧪。
2. 同类问题在 2 个以上镜头复现，或单变量对照测过，才升 ✅，必要时进本文件、能自动查的加进 h3q check。
3. 被推翻的规则从本文件和知识库里删掉，不再靠「作废清单」排除。
4. 改完把本文件顶部版本号改成当天日期。

**每集复盘**：每集审完写一页——一次过的镜头比例、返修次数、归因分布、新增或升级了哪些规则。用这个比例衡量系统是不是在变好。
