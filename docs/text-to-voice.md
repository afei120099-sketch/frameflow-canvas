# 文生配音节点

点击画布左下角加号，选择“文生配音”；或在画布空白处右键，选择“文生配音 · CosyVoice3”。也可打开命令面板搜索“配音”。

1. 选择配音模式：“AI音色设计 · 试听选角”、原有“参考音色 · CosyVoice3”、或系统基础“预设男声／女声 · 无需参考”。旧节点仍默认使用原有参考音色模式。
   - AI音色设计：填写角色音色描述（性别、年龄感、音域、质感、口音、自然说话方式等），选择1–3条候选。使用Qwen3-TTS-12Hz-1.7B-VoiceDesign，不需要用户录音；试听台词与正式配音台词分开保存，试听最多300字。候选串行生成，种子留空随机，数量和种子都可调整。
   - 参考音色：选择当前画布角色的主声音，或当前画布里已有的声音。模型使用已安装的 Fun-CosyVoice3-0.5B 标准版、自动设备、FP16。
   - 预设男声／女声：选“男声 · 康康”或“女声 · 慧慧”，直接填写台词即可生成。使用本机已有 Windows 中文语音包，纯离线、CPU运行，不上传台词，不新增模型，也不占用ComfyUI队列。输出为WAV。这是系统基础配音，不是CosyVoice音色克隆，不支持情绪指令或随机种子；语速0.5–2为系统近似倍率。缺少对应系统音色会明确失败，不自动切换声音。
2. 填写台词；语速默认为 1 倍，可设 0.5–2 倍；种子留空随机。语气要求可在折叠区修改。
3. 点击“生成配音”。参考模式进入 ComfyUI 队列；预设模式在本机CPU生成，无需选择参考声音。两种模式都不改动已有 H3 工作流。
4. 生成完成后在节点内试听（参考模式MP3，预设模式WAV）。两种模式都可点击“加入角色信息”，选择当前画布的已有角色或新建角色，保存后直接打开该角色信息。
5. 勾选“设为该角色的主声音”可替换主声音；原声音仍保留。未勾选时只加入参考声音列表；角色第一次添加声音会自动设为主声音。

## AI音色选角与后续自动沿用

在AI音色设计模式中，生成后每条候选都有独立播放器与“选中试听候选”按钮。点击“选中声音保存为角色主声音”，选择当前画布已有角色或新建角色；此入口默认勾选主声音。确认保存后自动打开角色信息，并将本配音节点切回CosyVoice3参考模式、绑定该角色，不需要重复选择参考录音。之后填写新的正式台词即可配音，生成前会读取该角色最新主声音；主声音丢失时会明确拦截，不会借用其他角色声音。

这不是每句重新设计音色：Qwen负责设计选角，选定的WAV作为角色主声音，CosyVoice3负责后续配音。角色声音是生成参考，不保证绝对无漂移，仍需试听。H3旧节点已经冻结的角色快照不因此自动改写。

候选、种子、音色描述和已选素材保存在节点中；生成输入、模型路径、候选WAV、耗时、显存分配记录还保存在 runtime/voice-design-jobs。角色主声音随原有完整项目备份保存。原始模型与独立Python环境不包含在项目媒体备份内。

模型固定为官方revision 5ecdb67327fd37bb2e042aab12ff7391903235d3，Apache-2.0；本机模型总计4,520,162,313字节，路径 runtime/models/Qwen3-TTS-12Hz-1.7B-VoiceDesign，权重SHA256见 frameflow-source.json。环境在 runtime/qwen-voice-design-env，不修改生产ComfyUI的Python、PyTorch或工作流。

参考：[官方模型](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign)、[官方音色设计说明](https://github.com/QwenLM/Qwen3-TTS#voice-design)。Windows使用PyTorch SDPA，没有安装FlashAttention；当前纯文本VoiceDesign路径不需要SoX命令行工具，导入时的缺失警告不代表本次生成失败。

GPU保护：开始前确认ComfyUI队列为空，至少8GiB空闲显存；每次最多3条，单进程串行，完成后退出释放设计模型。试听期间画布的ComfyUI新提交会被保护门拦截；检测到外部ComfyUI任务、队列失联、超时或80°C时停止自己的试听。刷新或暂停查询不会重新提交，节点可用“查询原试听任务”取回结果；失败不自动重试。

生成的声音会登记到当前画布素材库、本地声音存储和画布节点，可以保存/备份。每次生成保留一个版本，可切换试听旧版本。参考模式的 ComfyUI 文件保存在 output/audio/，名称以 Frameflow_CosyVoice 开头；预设模式的 WAV 保存在画布本地声音存储，名称以 Frameflow_Preset 开头，可直接下载。

需要裁剪时点击“放为声音节点”；重复点击会定位当前页面已有的同一声音节点。H3 的“添加声音”也可以直接选当前画布上文生配音节点的结果。

参考模式断开或刷新后，节点保留原任务 ID。点击“查询原任务”取回结果，不会再次提交；“暂停查询”只停画布查询，ComfyUI 里的任务继续。只有确认任务已不在队列/历史时，才显示“清除失效任务记录”，清除后可手动重新生成。预设模式没有 ComfyUI 任务 ID，点击“取消生成”会取消本机生成；页面关闭或刷新时不自动重试，尚未保存的结果需要手动重新生成。

普通手动参考音色在选择时固定为当时的录音；角色库以后换主声音，需要在这种旧节点中重新选择。通过AI选角保存主声音的节点会自动跟随角色最新主声音。现有 H3 节点已冻结角色声音时，仍需主动“重新读取角色库的外观 / 声音”才会使用新的主声音。

这是先生成一段独立配音。把它设为 H3 角色主声音，只是为 H3 提供音色参考，不等于强制逐字播放该 MP3。需要保留整段配音原声时，应使用原音轨锁定或后期配音方式。

兼容角色库早期保存在 media: 中的声音，使用时直接读取原文件，不迁移或改写已有声音记录。新增角色声音保存到专门的 audio: 声音存储。
