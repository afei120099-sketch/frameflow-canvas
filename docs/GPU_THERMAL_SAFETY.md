# GPU 温度保护

本地开发服务每 2 秒读取 NVIDIA GPU 核心温度，多 GPU 取最高值。关闭画布网页不会停止监测；关闭本地服务器后保护不再工作。

- 80°C 及以上：锁定画布/夜班 ComfyUI 新提交；清空本地 ComfyUI 待执行队列并请求中断当前任务（包括用户从 ComfyUI 界面排入的任务）。不会删除已有输出或历史。
- 请求中断不代表已经停止。队列为空才显示停止确认；连接失败时仍禁止新提交并继续尝试停止。
- 降到 75°C 以下、确认停止且保护记录可保存后，点击顶部提示里的“手动解除保护”。不会自动重跑被停止的视频；夜班需另行确认继续。
- 温度不可读：禁止新提交，但不会仅因为一次读数丢失而中断已运行任务。
- 锁定记录保存在 `runtime/autopilot/thermal-safety.json`（随夜班目录配置），服务重启仍保持锁定，损坏记录按锁定处理。属于夜班独立归档，不属于浏览器项目备份。

这是软件保护阈值，不是显卡损坏温度。保护仅覆盖经过本地服务器提交的 ComfyUI GPU 任务；不监测 CPU、显存热点，也不保证中断立即释放所有显存。不负责停止 Blender、LM Studio 或其他软件。直接绕过画布提交到 ComfyUI 的任务不经过提交门禁；锁定期间后台仍会尝试清队列和中断。硬件散热与驱动保护仍需正常工作。

自动测试：`node --experimental-strip-types scripts/test-gpu-thermal-safety.mjs`。使用模拟温度和独立模拟 ComfyUI，禁止为了验证保护让真实设备过热。
