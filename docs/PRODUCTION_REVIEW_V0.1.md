# 制作审核 V0.1

本轮借鉴分阶段审批思路，自行实现 TypeScript 小模块；没有安装、复制或执行 OpenMontage。费用预算不做。H3、Blender、Director Stage、Shot 生成链及冻结工作流未修改。

## 已接入

- 打开「成片序列」→「收齐已采用镜头」。按镜头板保存的顺序追加其启用、已采用的本地视频，保留入出点和备注；不替换旧片段、重复点击不重复追加。不自动采用候选，也不把采用冒充审核。
- 勾选「审核通过后再粗剪」。点选片段，在上方播放器检查人物、动作、声音，再点「通过」或「需重做」。后者只是标记，不会重新生成。
- 启用审核后，所有启用片段均需通过；未通过或审核过期时阻止粗剪，不偷偷漏掉镜头。暂不用的镜头可以停用。
- 审核绑定 Asset、来源、尺寸/文件大小/时长和裁切范围；素材或裁切变化后过期。标题、备注、排序不影响审核。
- 审核政策、记录保存在既有 finalCutList meta 中，随项目 v2 备份恢复；旧备份没有审核字段时继续自由剪辑。粗剪 Run 的冻结快照保留审核证据。

原来可自由加入任意视频、手动排序及真实 PyAV 粗剪的方式保持可用。审核是可选项，不影响旧项目。

## 没有新增/没有承诺

- 剧本拆镜头和后台批量排队仍使用既有夜班 M2，现有限制为 3–6 个文生镜头、15–60 秒、需求 500 字；不能宣称支持任意长度复杂剧本或参考图自动绑定。夜班磁盘账本仍须独立归档，不在项目浏览器备份中。
- 本轮不新增参考视频分析、视觉模型质检、配音/配乐生成、多平台路由。
- 原有粗剪会检查真实媒体读取、时长及裁切；新增审核不等于自动检测人物变形、黑帧或语音准确性。
- 不会因为标记重做而自动调用 H3；真实 GPU 出片和真人听音未在本轮验收。

## 回归

`npm run test:production-review`：审核阻断、素材/裁切失效、旧流程、顺序收齐、重复点击、来源校验、不改生成记录、备份恢复。另运行现有成片、粗剪、项目备份及生成链回归、TypeScript、ESLint、Build。

2026-10-05 已执行并通过：新增审核测试、成片清单/取消加入、真实 CPU PyAV 粗剪、项目备份、数据安全 Hotfix、H3、AddGuide、Shot、夜班 M2 11 组模拟回归、SDXL Depth 模板/模拟回归、TypeScript、生产 Build。未提交真实 GPU 任务。

实际内置浏览器用 CPU 生成的 4 秒色块测试视频验证：导入→加入成片→开启审核→待审核时粗剪禁用→预览→通过时恢复可用→改入点时审核过期→刷新保留审核政策、入点和过期状态。测试素材只存在测试浏览器数据中，没有操作用户 Chrome 项目。界面截图位于 `.claude/production-review-ui.png`。本轮没有验证真实人物画面质量或真人听音。
