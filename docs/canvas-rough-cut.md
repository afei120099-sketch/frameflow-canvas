# 画布内一键粗剪

## 怎么操作

1. 在当前画布框选几个已经有结果的视频，或按 Shift 多选。支持普通视频节点、H3 当前显示的候选／高清结果、原音轨视频结果。
2. 在选中的视频上右键，选择“一键粗剪”。没有生成结果的镜头会提示，不能拿空节点导出。
3. 默认按节点从左到右排序，同一横坐标再从上到下排序，和点击选中的先后无关。
4. 每个视频上方出现大序号，下方出现时间表：设置从几秒到几秒，默认完整视频。“预览片段”播放选中的截取区间。
5. 点击“前移／后移”，或通过“顺序”选择具体位置。序号会立即更新，原画布节点不移动，已设的截取时间跟着该片段保留。“恢复从左到右”按当前几何位置重新排序。
6. “移除”仅把这一段移出本次粗剪，不删除视频或素材。
7. 底部显示总段数、总截取时长。点击“确认并生成粗剪”，自动准备并开始本地剪辑；成功后画布上只增加一个粗剪成片视频，也可在完成窗口下载。

顶部的“成片序列”、视频节点的“加入成片”以及右侧成片序列框已移除。素材库、镜头板和血缘窗口的旧“加入成片”入口也移除，以免加入到不可见的旧清单。旧清单及备份数据仍保留，没有删除或自动迁移。

## 注意

- 本次粗剪草稿属于当前画布页面，切换页面不会把它显示到其他页面；返回原页面仍可继续。刷新页面或退出粗剪会结束这次未导出的草稿，原视频不会改变。
- 当前候选会在进入粗剪时固定下来；以后另选候选不会暗中替换本次待剪的视频。如需更新，重新多选后右键建立粗剪，会先询问是否替换草稿。
- 不改原片，也不提交 H3、高清或插帧任务。本地 CPU 硬切拼接，统一编码 H.264＋AAC；尺寸、帧率处理沿用现有粗剪规则（默认跟随首段尺寸，不同画幅保持比例加黑边）。这不是无损文件拼接，压缩可能带来少量变化。
- 越界、负数、结束早于开始、文件失效等情况会拦截并指出对应片段，不会跳过后假装成功。
- 片段预览按播放器时间更新在出点停止；导出由后端按实际时间戳裁剪，最终落在帧边界上。
- 生成时请保持页面打开。关闭或取消导出面板将取消该次粗剪，不影响原素材。

## 验证

已验证：默认排序、改序保留截取时间、非法范围拦截、旧清单不被写入、真实短视频预览、右键菜单入口、真实本地 CPU 裁切合并、只新建一条结果。验证使用隔离浏览器和合成测试视频，未改动用户当前画布、渲染队列或原视频。
